# beacon

Status: **no ONNX model**. Rules/statistics only: robust periodicity (median IAT, MAD-based dispersion) with asset-inventory context (flink/sih_detect/beacon.py). A classifier needs labelled beacon and OT-polling data.

This directory intentionally holds no model files. Adding one requires a trained, evaluated bundle written by model-training (see models/dga/README.md) and a deployment-manifest entry.
